## ✨ Features

### 📌 Core
- **Create, edit, and delete** notes instantly
- **Pin notes** to keep important ones on top
- **Sticky-note style cards** with random pastel colors
- **Full detail view** — click any note to read the complete text
- **Auto-saved** to `localStorage` (no backend needed)

### 🔍 Search & Filter
- **Live search** by title or content
- **Filter by tag** — Work, Personal, Ideas, Reminders
- **Clear search** with one click
- **Clear all notes** with confirmation dialog

### 🎨 Design & UX
- **6 pastel sticky-note colors** (yellow, pink, blue, green, purple, orange)
- **Handwritten title font** (Caveat) for a warm, personal feel
- **Smooth animations** — card hover tilt, staggered entrance, spring modals
- **Beautiful toast notifications** for every action
- **Custom thin scrollbars** matching the design
- **Fully responsive** — mobile, tablet, and desktop
- **Scroll-to-top** button appears on scroll

### 🌙 Theming
- **Dark mode & light mode** toggle
- **System preference detection** (`prefers-color-scheme`)
- **Manual override** saved to localStorage
- **Per-color text contrast** — every sticky note stays readable in both modes

### ⌨️ Keyboard Shortcuts
| Shortcut | Action |
|---|---|
| `Ctrl / Cmd + K` | Focus search |
| `Ctrl / Cmd + N` | New note |
| `Esc` | Close any open modal |
