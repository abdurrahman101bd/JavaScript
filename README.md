## 🎯 Why this repo exists

- Keeps every small project from my JavaScript learning in one place, instead of scattered across separate repos
- Lets me look back later and see what I learned, and when
- Anyone landing on my profile can open this repo, look around, and hopefully learn something from it too

---

## 🚀 Usage

Just open `index.html` in any modern browser — no build step, no dependencies to install.

```bash
git clone https://github.com/abdurrahman101bd/JavaScript.git
cd JavaScript
# then simply open index.html in your browser
```
