## 🚀 Features

- **5 Theme Colors** — One click to swap the whole UI color
- **Dark Mode** — Toggle with smooth transitions, saved in `localStorage`
- **Auto Theme by Time of Day** — Morning / Day / Evening / Night color based on your clock
- **3D Tilt on Mouse Move** — Card gently rotates for a premium feel
- **Drag-to-Change Hue** — Click & drag on the card to shift the color in real time
- **Confetti Burst** — Fireworks on the Follow button
- **Follow / Following Toggle** — Persists between reloads
- **Count-Up Stats** — Followers / Following animate from 0
- **Animated Gradient Blobs** — Floating background (no heavy blur filters)
- **Rotating Conic-Gradient Ring** around the avatar
- **Social Icons (SVG)** — GitHub, LinkedIn, X, Facebook
- **Persistent State** — Theme, dark mode & follow status saved in `localStorage`
