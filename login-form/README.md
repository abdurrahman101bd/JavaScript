# Login Form

A modern, fully functional login form built with vanilla HTML, CSS, and JavaScript. Features a theme toggle (light/dark), password visibility toggle, forgot password dialog, sign-up dialog, and success confirmation — all with smooth animations and a clean, responsive UI.

> Built while learning JavaScript.

---

## ✨ Features

- **Dark / Light theme** — toggle in navbar, saved in `localStorage`
- **Password show/hide** — eye icon toggles between `text` and `password`
- **Modern UI** — soft shadows, rounded corners, gradient background
- **Fully responsive** — works on mobile, tablet, and desktop
- **Forgot Password dialog** — sends reset link (with email input)
- **Sign Up dialog** — name, email, and password fields
- **Success dialog** — animated confirmation after login/signup
- **Keyboard support** — `Escape` closes any open dialog
- **Overlay click** — click outside dialog to close
- **Accessibility** — ARIA labels, focus management, reduced-motion support
